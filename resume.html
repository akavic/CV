Key Projects

Audio Editing & Generation Tool

Solo Final Year Project

Vanilla JavaScript · Web Audio API · WaveSurfer.js · browser DAW

  • Built a browser-based digital audio workstation from scratch in vanilla JavaScript on the Web Audio API, with WaveSurfer.js for waveform and spectrogram visualisation — a full editing environment, not a single-file playback demo.
  • Designed a custom audio signal chain from raw GainNode and DelayNode graphs to implement real-time reverb and delay, rather than relying on a pre-built effects library. The hard part was keeping the graph stable and latency acceptable while decay, mix, and feedback changed live — which meant owning the routing, wet/dry mix, and parameter updates instead of hiding them behind a plugin API.
  • Developed a multi-track mixer with independent per-track volume, pan, reverb, and delay, each with its own processing chain, summed cleanly to a master output without one track’s effects bleeding into another.
  • Implemented drag-and-drop import (WAV, MP3, OGG, FLAC), region selection and markers for editing, and track-merging to combine multiple sources — the actual DAW workflow of bringing audio in, isolating a region, processing it, and bouncing a mix.
