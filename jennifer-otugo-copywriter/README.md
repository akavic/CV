## Export to PDF

Open `cv.html` in Chrome/Edge → **Ctrl+P** (Windows) or **Cmd+P** (Mac) → Destination: **Save as PDF** → Paper size: **A4** → Margins: **Default** → enable **Background graphics** if offered → Save.
